# Responsive Product Pricing Cards

A responsive, accessible SaaS pricing page built with HTML, CSS, and vanilla JavaScript.

## Features

- Responsive pricing card layout
- Monthly and yearly billing toggle
- Keyboard navigation and ARIA state updates
- Highlighted popular plan
- Accessible focus states and reduced-motion support
- No build tools or external dependencies

## Getting Started

Open `index.html` directly in a browser, or serve the project locally:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
